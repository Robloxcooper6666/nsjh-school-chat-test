技術核心架構 (Tech Stack)

Firebase (Database & Auth)

負責長期資料存儲與匿名身分驗證。當訊息發布時，資料會先寫入 Firestore 並觸發快取機制。

Ably Pub/Sub (Real-time)

使用發布/訂閱模式（Pub/Sub）。前端 JavaScript 訂閱特定 Channel，一旦有新消息，Ably 會立即推送到所有連接的設備。

architecture.js
// 簡化版傳輸邏輯
const channel = ably.channels.get('nsjh-live');

// 發布訊息
channel.publish('new-post', {
  user: 'Student',
  text: 'Hello NSJH!',
  timestamp: Date.now()
});

// 接收即時更新
channel.subscribe('new-post', (msg) => {
  renderToUI(msg.data);
});

前端採用的核心 Event-Driven 架構，保證了訊息的即時性與一致性。
